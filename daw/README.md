# PocketDAW

iPhone（iPhone Duo の外側 5.4 インチ／内側 7.6 インチ画面を含む）の Safari で動く、インストール不要のマルチトラック DAW です。
ビルド工程はなく、このフォルダをそのまま HTTPS で配信すれば動きます。

## できること

- シンセ（7 プリセット＋波形・フィルター・ADSR の調整）、ドラム（12 パーツ）、オーディオの 3 種類のトラック
- タイムラインでのクリップ移動・長さ変更・複製・分割、ループ再生、メトロノーム
- ピアノロール／ドラムグリッドでの打ち込み（グリッド、クオンタイズ、ベロシティ、範囲選択）
- 画面の鍵盤・パッドのリアルタイム録音、マイク録音、音声ファイルの読み込み
- ミキサー（音量・パン・リバーブ・ディレイ・ミュート／ソロ・メーター）とマスターリミッター
- 取り消し／やり直し、端末内への自動保存（IndexedDB）、WAV 書き出し
- ホーム画面に追加するとオフラインでも起動（PWA）

## 使い方

```sh
cd daw && python3 -m http.server 8000   # http://localhost:8000
```

iPhone で使うには HTTPS で配信してください（マイク録音とオフライン起動に必要）。
`main` に入ると `.github/workflows/daw-pages.yml` が GitHub Pages へ公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく必要があります）。
Safari で開いて共有メニューから「ホーム画面に追加」するとアプリのように全画面で使えます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 音声エンジン（シンセ、ドラム、ミキサー、スケジューラ、マイク入力、オフライン書き出し） |
| `app.js` | 画面と編集操作、保存 |
| `style.css` | 見た目（ライト／ダーク対応） |
| `sw.js`, `manifest.webmanifest` | PWA 設定 |
| `tools/build-artifact.mjs` | 1 ファイルにまとめた HTML を出力 |

## 制限

- MIDI キーボード入力は未対応（iOS Safari に Web MIDI がないため）
- オーディオのタイムストレッチはなし（テンポを変えても録音の長さは変わりません）
- プロジェクトは端末のブラウザ内に保存されます。別端末への移行機能はありません
